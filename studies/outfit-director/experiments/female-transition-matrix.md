- 主体：同一虚构成年女性

## 外部视频评分表

每项使用 0–2 分：`0 失败`、`1 部分成立`、`2 稳定成立`。

| 指标 | 说明 |
| --- | --- |
| 身份一致性 | 脸、发型、肤色和身材比例是否稳定 |
| 服装正确性 | 是否按目标顺序改变，是否叠穿或混合 |
| 机制服从度 | 是否执行所选机制，而不是普通溶解或无因果瞬切 |
| 动作连续性 | 重心、方向、手臂轨迹和视线是否承接 |
| 衣料物理 | 裙摆、长袖、披帛或流苏是否自然 |
| 画面完整性 | 是否出现双影、多余人物、肢体错误或背景突变 |
| 卡点同步 | 换装完成点与预设时间是否接近 |
