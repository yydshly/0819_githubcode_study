## 已落地闭环

TEST C 现在提供：

1. 默认人物、服装和预生成结果三图对照，持续标注为非模型推理。
2. 上传任一自定义图片后立即清除演示结果，可一键恢复且不请求网络。
3. 人物图与服装图双输入，本地 Object URL 预览。
4. JPG / PNG / WebP、10MB 上限、分辨率与人物图比例建议。
5. 上装、下装、连衣裙类别选择。
6. 仅允许 `localhost` / `127.0.0.1` 的健康检查。
7. 服务在线、两张自定义图片都存在时才允许真实推理。
8. 成功只接受 `image/*` 响应；失败保留明确空状态，不补假图。

客户端无法判断头脚是否完整、手臂是否遮挡躯干、服装是否真为单件商品图，因此这些仍是人工输入门槛。真实推理服务以后再负责人体解析、姿态、自动遮罩和扩散推理。

## E004 验收设计

- 固定一张非敏感正面全身人物照。
- 固定至少三件商品图：上装、下装、连衣裙各一件。
- 保存原始输入、模型 commit、权重标识、尺寸、seed、耗时和峰值显存。
- 对照身份、面部与头发、服装纹理/文字、手臂遮挡、轮廓、背景稳定性。
- 失败结果同样保留，不只展示最好的一张。
