# 本地 VTON 适配器契约

这个目录定义 Outfit Director Web 与真实 2D 虚拟试衣模型之间的稳定边界。当前只提交接口契约，不包含模型权重，也不声称已经完成推理。

## 为什么需要适配器

CatVTON、IDM-VTON 或后续模型都有不同的预处理、遮罩、参数和运行环境。Web 只依赖这里的两个端点，因此更换模型时不需要重写上传和结果界面。

- `GET /health`：报告本机服务、模型和设备状态。
- `POST /api/v1/try-on`：接收人物图、服装图和类别，成功时直接返回一张图片。

完整字段见 [openapi.yaml](./openapi.yaml)。

## 第一候选

首轮选择 [CatVTON](https://github.com/Zheng-Chong/CatVTON)：官方仓库说明在 `bf16` 下生成 `1024×768` 约需 8GB 显存。本机 RTX 4070 Laptop 检测到 8188 MiB，理论上接近门槛，但仍需实际记录峰值显存、耗时和 OOM 情况。

IDM-VTON 保留为质量对照。两者代码和权重均采用 CC BY-NC-SA 4.0，只能在符合署名、非商业和相同方式共享要求的研究范围内使用。

## 安全与隐私边界

- Web 仅允许 `localhost` 或 `127.0.0.1`，避免误把真人照片发往未知远端。
- 图片在选择后仅通过 Object URL 本地预览。
- 只有用户点击“开始真实试衣”时才发送到本机适配器。
- 适配器实现应默认不保存输入与结果，不记录原始图像内容。
- CORS 只需允许研究页面的本机来源，例如 `http://127.0.0.1:4173`。
