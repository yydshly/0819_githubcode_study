# Blobatar 演示交接

## 项目与阶段

Blobatar 研究子项目 R2 已完成。固定上游代码、身份定位描述、社区 / 多 Agent Web 扩展、研究记录、索引和 Pages 部署入口均已建立。

## 已完成

- 上游固定到 `9946e7c` / package 2.2.0。
- 真实上游 TypeScript 和 motion CSS 已构建为本地静态资产。
- Seed、规范化、形状、背景、色相、色调、14 种表情、动画、下载和群组实验已接入。
- 增加 Identity Protocol Lab：社区显示 6 个稳定默认身份；多 Agent 显示研究、检索、写作、审核四个角色。
- 增加待命、分析、执行、复核、完成五阶段状态映射，并保留文字语义与键盘 tab 操作。
- 定位已收敛为“头像回答谁、表情动效提示状态、文字提供准确语义”。
- 使用场景、能力边界、原理和 P1–P6 扩展路线已写入页面和研究 README。
- 根索引、研究门户和 GitHub Pages 工作流已接入 Blobatar。
- 1440 / 1024 / 390、核心交互、键盘、下载和 reduced-motion 浏览器验收通过；证据见 `validation.md`。

## 运行入口

```powershell
python -m http.server 4180 --directory demos/blobatar
```

Canonical URL：<http://127.0.0.1:4180/>
