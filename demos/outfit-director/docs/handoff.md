# 交接说明

## 项目与阶段

Outfit Director 能力实验室是研究主库中的第一个交互演示。提示词导演、网页换装双实验，以及项目级虚拟试衣技术路线的本地实现和浏览器验收已经完成，当前处于可交付状态。

## 已完成

- 设计契约和覆盖矩阵。
- 零依赖、GitHub Pages 兼容的静态页面。
- 女性、男性、宠物和 K/D 两种模式的规则模拟。
- 5/7 造型 SVG 首帧母图、侧边造型消费状态机和时间轴。
- 参数、首帧、视频、负面提示词与复制反馈。
- A 实验：图像/视频模型策略选择、本地人物与衣服素材编号、模型感知提示词。
- A 默认路线调整为纯文本 T2V：一次提交后直接显示并复制外部视频模型提示词；I2V 路线保留首帧与素材控制。
- B 实验：同一虚构成年人物的五套写实造型、手动选择、自动换装、重置与边界证明面板。
- B 新增柔和溶解、布料扫光和卡点闪切三种过渡效果，支持手动和自动播放。
- 女性专项规则数据层：通用/女性 profile、M1–M13 机制和四类造型预设相互独立，可继续扩展。
- A 女性专项导演：按需展开妆容、配饰和衣料字段，M1–M12 可选并写入参数、时间轴和视频提示词；男性/宠物自动回到通用导演。
- B 女性机制模拟：M1 人物飞入、M2 袖摆遮镜、M8 贴纸翻页、M10 动作卡点；其余八种明确保留为外部模型提示词机制。
- 女性变体研究文档、F001–F012 实验矩阵及 MIT 来源与版本说明。
- E001 MiniMax H3 真实视频：原始 MP4、封面、完整提示词、SHA-256、媒体事实、关键帧和换装点观察。
- Web E001 结果区：原生播放器、直接 MP4 入口、基线状态、实际/目标参数和完整提示词折叠区。
- E001 规则回归：纯 T2V 的 M13 不再同时要求侧边激活与禁止侧边人物，改为单主体舞蹈峰值原地换装；I2V 仍保留侧边造型消费逻辑。
- 总体规划：五个技术目标、M0–M7 阶段、能力接入矩阵、子项目拆分、验收门槛与近期 E001 动作。
- Web 路线面板：可切换提示词视频、2D AI 试衣、3D 参数化试衣、实时 AR、尺码与穿搭智能，并查看每项输入、依赖、步骤、输出和完成标准。
- 路线与现有实验联动：目标一进入提示词实验；目标二进入当前 2D 视觉原型，同时保留“非真实试衣”边界。
- OpenAI 内置图像生成工具创建的项目本地素材 `assets/fictional-model-five-looks.png`。
- 深浅主题、桌面/平板/手机、键盘和 reduced-motion 支持。
- 真实浏览器验收与基础性能观察。
