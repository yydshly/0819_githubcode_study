05 / WHERE TO USE

什么场景下值得使用

判断标准不是“有没有字幕”，而是内容是否能拆成少量、清晰、按顺序出现的视觉对象。

GOOD FIT适合直接使用
  • 知识讲解概念、因果、步骤和对象关系清楚
  • 课程与培训旁白稳定，可提前完成分镜和配图
  • 故事口播人物少、场景简洁、事件按顺序发生
  • 流程说明输入、处理、输出可视化为三个以上模块
CONDITIONAL满足条件再用
  • 品牌短视频需要先替换固定米黄画风和手部素材
  • 复杂技术架构应先转换为分层 SVG，避免大矩形互相遮挡
  • 批量生产需要补充自动标注、失败恢复和质量测试
  • 照片输入只适合轮廓清楚、背景干净的图片
POOR FIT不建议使用
  • 写实动作视频没有人物运动、镜头运动和物理动作生成
  • 复杂摄影画面阈值化会把纹理、阴影误识别为墨迹
  • 真实书法笔顺路径来自启发式追踪，不是原作者落笔数据
  • 无人值守生产源图和语义区域仍依赖 Agent 或人工确认
06 / RESEARCH VERDICT

它能稳定执行，但不能独立理解

这个边界决定了它是“渲染后端”还是“一键视频产品”。目前证据只支持前者。

VERIFIED

已经证实的能力

  • 字幕时间解析与按时长分场景
  • 三个语义区域按时间顺序揭示
  • 后续区域遮罩保护，不提前露线
  • Grid / Skeleton 两类笔迹入口
  • 轮廓扫描或轨迹笔刷上色
  • 60 FPS H.264 MP4 稳定输出
EXTERNAL

需要外部能力

  • 根据字幕理解叙事事件
  • 生成统一风格的源图
  • 识别图中对象并创建区域标注
  • 配音、字幕烧录和音视频混流
  • 复杂对象的像素级分割
  • 发布平台封面、文案和分发
CURRENT RISK

当前工程风险

  • 上游只有一个提交，没有正式 Release
  • 没有测试、CI 和依赖版本锁
  • 矩形区域对复杂重叠对象过于粗糙
  • 元素按开始时间串行渲染，不支持真正并行
  • 背景识别依赖四角采样，照片输入不稳定
  • 输出没有旁白、字幕和 BGM
6.5/10

阶段结论

值得研究其“语义编排 + 确定性渲染”的组合，不应把它误判为端到端文生视频系统。
