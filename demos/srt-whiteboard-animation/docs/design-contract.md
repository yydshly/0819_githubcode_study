# SRT Whiteboard Animation 研究页设计契约

## Design Contract

```text
Entry mode: Brief-led extension in an active static research site
Request revision: 3
Target user and context: 正在判断该库是否可控、如何驱动、何时使用的研究者与内容生产者
Desired first impression: 先看到真实成片，再立即理解它不是“一键 SRT 生视频”，而是可配置的编排与渲染链路
Visual ambition: Editorial
Experience architecture: Editorial Flow
Visual constraints: 暖纸张、深墨线、少量橙红/蓝绿信号色；保留研究站的编号、证据和边界表达；避免通用后台仪表盘外观
Information constraints: 真实视频优先；控制面、输入协议、适用场景、能力边界和复现证据必须同页可达
Operation constraints: 零构建依赖、无后端；控制台只模拟并生成真实 CLI/annotation 配置，不虚构浏览器内渲染能力
State constraints: 默认参数、参数变更、时间点跳转、复制成功/失败反馈；静态页无加载与远程错误状态
Environment constraints: 相对路径静态部署；支持桌面、平板和 390px 手机；中文界面；页面仅声明浅色主题
Primary journey: 选择物理原理案例 → 播放真实成片 → 依次查看 SRT、源图、annotation.json、CLI 与输出 → 对照理解“静态插画如何逐步变成视频”
User-defined phases: 1. 看到物理原理的真实动画；2. 逐步查看如何驱动生成；3. 对照前三个案例理解方案边界；4. 阅读研究结论
Required artifacts: index.html、styles.css、app.js、四个真实案例及物理案例的源图/SRT/annotation.json/MP4、可点击五步生成链路、设计契约、浏览器验收、交接说明、Pages 部署入口
Autonomy authorization: 用户明确要求“请用一个 web”，授权在现有研究站约定内直接实现可逆的静态页面与导航接入
User-decision boundary: 不增加后端、真实渲染 API、登录、外部服务或新的媒体生成成本
Observable completion criteria: 页面可运行；四个真实案例均可播放；牛顿第三定律案例由上游脚本实际渲染；案例可切换；五步链路展示其真实 SRT、源图、annotation.json、CLI 与输出；原有案例与控制台继续有效；桌面/平板/390px 无遮挡；键盘可达；reduced-motion 有效；无控制台错误
```

## Brief-led 设计方向

| 决策 | 选择 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 首屏层级 | 左侧结论与入口，右侧真实视频 | 视频与“控制台”入口必须在首屏或紧随首屏 | 第一次扫描能回答“它做什么”和“效果在哪里” |
| 内容路径 | 效果 → 控制台 → 数据协议 → 场景 → 边界 | 不先铺陈长篇背景 | 主流程标题按此顺序出现 |
| 视觉语言 | 暖米黄纸面、深灰墨线、手绘路径与编辑标记 | 装饰不能遮挡内容或模拟不存在的能力 | 无视频时正文仍完整可读 |
| 控件 | 原生 button/range/checkbox，明确焦点环 | 所有操作可用键盘完成 | Tab 顺序合理、焦点可见、按钮状态可读 |
| 动效 | 只用于时间线进度与复制反馈 | reduced-motion 下关闭非必要过渡 | 信息不依赖动画显现 |
| 响应式 | 桌面双栏，平板/手机单栏 | 控制台、代码和时间线不得横向溢出 | 1440、768、390px 均可完成主旅程 |

## Revision 2 方向增量

| 决策 | 选择 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 案例覆盖 | 故事叙事、知识解释、流程说明 | 三者必须使用不同内容与可见的渲染参数组合 | 选择器能切换三条真实 MP4 和各自工件 |
| 驱动解释 | SRT → 源图 → annotation.json → CLI → MP4 五步链路 | 代码与媒体必须来自仓库内真实文件，不使用概念占位 | 每一步可点击且内容随案例同步切换 |
| 页面层级 | 保留原首个成片，把多案例流程置于其后、控制台之前 | 新模块不能削弱“先看效果”的首要阅读路径 | 首屏保持不变，向下立即进入案例比较 |
| 响应式 | 桌面双栏工件台，窄屏纵向排列 | 选择器、步骤按钮和代码不得溢出 | 1440、768、390px 均可完成案例切换与五步查看 |

## Revision 3 方向增量

| 决策 | 选择 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 物理原理 | 牛顿第三定律：火箭升空 | 画面拆成燃烧、向下喷气、向上反作用三段，不依赖图中文字 | 三段字幕与三个独立区域一一对应 |
| 渲染真实性 | `skeleton + brush + hand` | 必须用上游 Python/OpenCV 生成实际 MP4 | ffprobe 与中间帧证明顺序和编码成立 |
| 案例扩展 | 保留共享五步工件台，增加第四个案例 | 不新建重复页面；四个案例使用同一交互模型 | 切换后标题、参数、工件和视频全部同步 |
| 响应式 | 桌面四列、平板两列、手机单列 | 案例标签与焦点环不可裁切 | 1440、768、390px 无横向溢出 |
