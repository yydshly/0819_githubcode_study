# 交接说明

## 项目与当前阶段

`bigpeng-hot-gzh` 是一个公众号选题与标题 Agent Skill。本研究已完成上游版本锁、能力研究记录、零依赖交互演示、研究总入口和 Pages 组装路径。本次范围已关闭。

## 已完成

- 上游锁定为 `8967879bbd59bfacfeb2d66214f095dc92b6f6bc`，MIT。
- 路径 A：6 条不同公式标题、字数、QA、兑现与首选。
- 路径 B：4 个不同模板方向，每个方向 3 条标题。
- 预设、自定义槽位、Agent 指令复制、结果复制和深浅主题。
- 明示区分 Skill 规则、宿主 LLM 和外部搜索/数据能力。

## 未做与有意边界

- 没有接入真实 LLM 或 Web Search；这些需要后端、密钥、成本和额外授权。
- 没有热点爬取、点击率预测、公众号发布或正文生成。
- 浏览器生成是确定性规则复现，用于解释能力形状，不是上游 Skill 的模型执行。

## 验证证据

- 规范 URL：<http://127.0.0.1:4178/>
- 视口：1440×900、768×1024、390×844。
- A/B 路由、自定义输入、Clipboard、主题、键盘、焦点和 reduced-motion 通过。
- 无水平溢出、page error 或 console error。
- 详见 [`validation.md`](validation.md)。

## 下一次最有价值的工作

如果继续研究，先建立带真实曝光、点击、阅读完成和账号规模标签的正负样本，然后比较通用 LLM、少样本 Prompt、完整 Skill 和人类编辑。在没有数据之前，不应继续扩展“爆款公式”数量。
