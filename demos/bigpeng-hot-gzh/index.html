02 / MECHANISM
模糊想法如何沉淀为可发布主题

        

        
    
          
  1. 01用户提供想法
    可以是关键词、一句话想法，也可以是已有草稿。
    2. 
          
  2. 02大模型明确
    理解意图，抽取读者、对象、数字、结果、冲突和证据。
    3. 
          
  3. 03Skill 规则驱动
    路由 A/B，再用 7 种标题公式和 8 种选题模板约束生成。
    4. 
          
  4. 04按规则质检
    查长度、虚假数字、同义改写和正文兑现承诺，再提出首选。
    5. 
          
  5. 05用户确认沉淀
    用户选择最终主题与标题；推荐代表规则匹配，不代表点击率预测。

03 / EVIDENCE BOUNDARY
哪些是库的能力，哪些需要外部系统

          
能力演示最容易失真的地方，是把宿主模型或 Web Search 的能力也算在 Skill 身上。

        

        

          

            UPSTREAM / NATIVE
上游 Skill 提供

            
  • A/B 任务路由
  • 7 种标题公式
  • 8 种选题模板
  • QA 与 Markdown 输出规范

          

          

            HOST / REQUIRED
宿主 Agent 提供

            
  • 理解任意草稿
  • 根据上下文补齐槽位
  • 生成自然且不重复的中文
  • 执行发出前自检

          

          

            EXTERNAL / OPTIONAL
外部数据与系统

            
  • 空输入时的当前热点
  • 公众号曝光与点击数据
  • A/B 测试与效果归因
  • 正文、配图、CMS 发布
