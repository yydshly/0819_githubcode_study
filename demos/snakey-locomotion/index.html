RESEARCH NOTES

从效果到可复用能力

原项目证明了：无需骨骼、烘焙动画和物理引擎，也能完成一套有环境反馈的长体生物场景。

  1. 01
    轨迹跟随身体

    每 6cm 记录一次头部位置、表面法线和接地因子，再按身体弧长采样。

  2. 02
    动态扫掠网格

    从切线和法线构造截面，每帧更新 BufferGeometry 顶点与法线。

  3. 03
    解析曲面运动

    高度函数负责贴地，胶囊体最近点与切平面负责树干和树枝攀爬。

  4. 04
    环境反馈

    RenderTarget 保存蛇身印记，实例化草叶读取强度与梯度后倒伏并恢复。

能力边界

这是视觉运动学 Demo，不包含真实摩擦、肌肉、受力、自碰撞或机器人控制。

真正值得带走的不是“复制一条蛇”，而是四个可以跨项目复用的表示方法。

PATH

PathHistory

把运动历史变成按弧长查询的数据结构，隔离头部控制与身体表现。

sampleByDistance(d)
MESH

DynamicSweep

沿三维路径建立稳定局部标架，实时生成管道、触手和长体角色。

P = C + aRcosθ + bUsinθ
SURFACE

SurfaceAdapter

统一地形高度、解析几何和未来 SDF/网格表面查询。

closestPoint(position)
FIELD

InteractionField

用会衰减的纹理保存环境记忆，驱动草地、雪地、泥地和危险场。

state = state × decay + stamps
