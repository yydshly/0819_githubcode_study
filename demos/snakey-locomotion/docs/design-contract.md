# Snakey Locomotion Web 研究展厅设计契约

```text
Entry mode: brief-led
Request revision: 2
Target user and context: 从研究总入口进入、希望理解 Three.js 程序化场景技术并判断后续复用价值的中文开发者与研究者
Desired first impression: 这是一个可以操作、可以拆解原理、也能看见扩展路线的实时 WebGL 研究台
Visual ambition: Immersive
Experience architecture: Spatial Stage
Visual constraints: 3D 场景始终占据主舞台；研究与参数面板作为克制的前景层；延续研究门户的深色技术气质，使用蛇鳞绿与琥珀色作状态信号
Information constraints: 清楚区分上游已实现能力、当前独立复现、可学习机制与规划扩展；首屏不依赖滚动即可进入核心体验
Operation constraints: 无后端、无登录、无真实外部 API；桌面支持 WASD/方向键和面板操作；窄屏支持触控方向键与底部研究抽屉
State constraints: 地面蜿蜒、曲面攀爬、交互场观察、结构解剖四种实验状态；运行/暂停；调试层开关；WebGL 失败回退
Environment constraints: Three.js + TypeScript + Vite；GitHub Pages 静态部署；桌面、平板、390px 手机；单一深色主题；支持 reduced-motion
Launch constraints: 源码 `index.html` 不是独立静态文件；真实体验必须通过 Vite 或 Pages 的 HTTP 地址加载；误用 `file://` 时显示明确命令和正确入口，不呈现残缺界面
Archive constraints: 项目标记为“已归档 / 按需复用”；保持演示与研究资料在线；不承诺主动迭代；恢复必须由长体角色、交互植被、曲面运动等具体需求触发
Primary journey: 打开展厅 → 观察自动运行场景 → 切换实验模式 → 调节运动参数或开启结构调试 → 打开研究抽屉理解可学习点与扩展模块 → 返回总入口
User-defined phases: 能力展示；可学习拆解；可复用扩展；总入口与 Pages 接入；浏览器验收
Required artifacts: 可运行 WebGL 展厅、研究说明、上游版本锁、总入口卡片、根 README 索引、Pages 构建配置、浏览器验收与交接文档
Autonomy authorization: 用户明确要求“继续，用 Web 的方式进行能力展示，以及我们的可学习扩展”，授权在现有研究库中直接实现可逆的前端与文档变更
User-decision boundary: 发布远端、提交、推送、引入后端或真实外部服务、将研究原型宣称为生产库
Observable completion criteria: 本地构建通过；真实浏览器可进入四种模式并操作参数；桌面/平板/390px 无不可达主控件或横向溢出；移动研究抽屉支持关闭/Escape/焦点返回；键盘路径和可见焦点有效；reduced-motion 不自动播放；WebGL 失败时保留可读研究内容；总入口与部署路径完整
```

## 空间舞台约束

```text
Scene base: WebGL / Three.js
Scene persistence: 主体验全程保持可见；研究信息在桌面右侧浮层或移动端底部抽屉中展开
Foreground control model: 顶部状态栏、左侧实验控制、底部运动提示、右侧研究抽屉
State-to-scene mapping: 地面模式显示轨迹驱动；攀爬模式切换为圆柱表面螺旋轨迹；交互场强化环境痕迹；解剖模式显示路径、采样环和局部标架；暂停状态冻结模拟但保留信息操作
Mobile transformation: 左侧参数折叠为紧凑控制卡；研究面板变为可关闭底部 sheet；提供屏幕方向键
Fallback: WebGL 或脚本不可用时显示语义化能力摘要、学习模块和扩展路线，主导航仍可用
```

## 设计方向

| 决策 | 选择 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 主视觉 | 持续可操作的 3D 林地与程序化蛇 | 场景占满视口，不退化为卡片缩略图 | 首屏第一注意力落在运动中的蛇和轨迹反馈 |
| 信息层级 | 实验模式优先，研究解释次之，指标辅助 | 同一时刻最多一个主要研究面板展开 | 不阅读长文也能完成模式切换与参数实验 |
| 色彩 | 墨黑、苔绿、暖白、琥珀信号色 | 状态不能只依赖色彩，按钮同时有文字和选中标记 | 选中、焦点、暂停和错误状态都可识别 |
| 材质与深度 | 半透明深色仪器面板，细线框与轻模糊 | 面板不能遮挡蛇头和主要路径 | 桌面场景仍保留至少 60% 可视宽度 |
| 动效 | 运动用于解释轨迹、相位和环境反馈 | reduced-motion 首次进入暂停，CSS 取消非必要过渡 | 信息不因关闭动画而丢失 |
| 能力边界 | 页面明确标记“独立研究复现”与“上游能力” | 不把简化演示描述成真实生物力学 | 研究抽屉能找到来源、许可证和限制 |

## 支持边界

- 只支持深色主题；主题切换不在本次范围内。
- 本次独立复现轨迹驱动、曲面法线、交互场和实例化植被等核心机制，不声称逐像素复制上游作品。
- 不加入真实生物力学、摩擦动力学、自碰撞、通用三角网格攀爬或多人同步；这些作为扩展路线展示。
- 原项目采用 MIT 许可证；引用和衍生说明必须保留上游作者、仓库与许可证信息。
